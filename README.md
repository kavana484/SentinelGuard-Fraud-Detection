SentinelGuard – Credit Card Fraud Detection
Project Overview
SentinelGuard is a Machine Learning-based project designed to detect fraudulent credit card transactions.
It uses a trained Machine Learning model to classify transactions as:
0 – Legitimate Transaction
1 – Fraudulent Transaction
Technologies Used
Python
Machine Learning
Pandas
NumPy
Scikit-learn
Gradio
Project Files
app.py – Application code.
fraud_detection_model.pkl – Trained Machine Learning model.
Features
Detects fraudulent transactions.
Predicts transaction status.
Provides an interactive user interface using Gradio.
How to Run
Install the required libraries and run:
python app.py
